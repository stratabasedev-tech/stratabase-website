Field workflow

A clear path from site to project record.

Field data is captured where the work happens, then becomes available for review when the device reconnects.

01 · Prepare

Create the project and investigation locations, select the relevant methods and confirm the logging fields before mobilising.

02 · Capture

Work through core runs, geology intervals, discontinuities, test pit horizons, laboratory samples and other supported modules. Choose a table order that suits how you are logging.

03 · Work without a connection

Previously authorised and prepared devices can continue capturing locally when internet access is unavailable. Protect unsynchronised observations with device recovery checkpoints.

04 · Sync and review

Once online, synchronise and review status and conflicts. Successful cloud synchronisation makes project records available to other approved users and devices.

05 · Safeguard

Organisation archives cover synchronised project records, while project backup exports support selective exchange and recovery. A tested restore workflow remains essential.
