The platform

A workspace for ground investigations.

StrataBase combines structured investigation data with a practical field interface.

Projects, locations, records

Each project contains investigation locations such as geotechnical boreholes, rock-mechanics boreholes, test pits and percussion holes. Logging data is held against the location that generated it.

Field logging modules

Capture geology, coring/recovery, structures and discontinuities, samples and supporting field measurements. The modules visible in a project follow its investigation type and logging configuration.

Review and export

Sort tables by depth or recent entry, inspect records across a project, and prepare supported data summaries and printable investigation logs.

Connected project data

Approved users can work across connected devices using cloud synchronisation. Offline-capable devices retain local data while out of coverage.
