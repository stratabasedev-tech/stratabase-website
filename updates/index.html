THE DEVELOPMENT LOG

News & release notes

Open any version to see what changed. Production field candidates, development testing, and historical archives are clearly separated.

Archive note: Early version dates are based on retained ZIP timestamps, not independently verified public release dates. Details are published only where supported by project records.

v0.9.9.5 Alpha 2Testing5 November 2026⌄

Project Library search, sorting and country filters; in-app Quick Log preview; laboratory Sample List with Batch Edit shortcut; streamlined QC summary and sidebar refinements.

  • Project library search, sorting, country/status filtering introduced in development.
  • Quick Log in-app factual preview and selected-investigation PDF access added for testing.
  • Laboratory Sample List and sample Batch Edit entry points introduced.
  • Log Review and QC summary navigation integrated into Data Review.
  • Desktop sidebar and release-notes presentation iterated; formal reviewer approvals remain under development.

Status / limitations: Development candidate only. Formal reviewer approvals and selective offline downloads are not active; full workflow testing is ongoing.

v0.9.9.5 Alpha 1Testing5 November 2026⌄

Field workflow consistency improvements, batch-edit pagination, recovery QC override, Data Review layout and update handling improvements.

  • Expanded depth carry-forward and geological description reuse behaviours.
  • Added Batch Edit pagination and an explicit excessive-recovery QC exception path.
  • Introduced collapsible Data Review sections, desktop sidebar controls and update-notification revisions.
  • Development checks passed; live field and multi-device regression testing remains necessary.

Status / limitations: Development candidate; live multi-device integration and full lifecycle QA incomplete.

v0.9.9.4Field candidate5 November 2026⌄

Import exception handling for invalid source rows, earlier SPT/Point Load fixes, and Windows PWA icon updates.

  • Added import exception handling: invalid source rows can be excluded with an exception report while valid records proceed.
  • Retained recovery, SPT and Point Load improvements from development candidates.
  • Updated Windows PWA icon assets and manifest references.
  • Released as a controlled production field candidate; later QA identified form and review issues.

Status / limitations: Controlled field candidate; additional QA and fixes identified.

v0.9.9.3Development candidate5 November 2026⌄

In-situ form state fixes and missing-field geological inheritance on editing existing Point Load records.

  • Fixed inconsistent in-situ SPT/Point Load form visibility when editing or changing test method.
  • Improved geological material and weathering inheritance for existing Point Load tests when fields are missing.
  • Preserved manually entered geological descriptions when editing.

Status / limitations: Candidate status; do not treat as an independently certified stable release.

v0.9.9.2Development candidate5 November 2026⌄

Styled discontinuity follow-up, SPT running blow calculations and Point Load geological inheritance.

  • Replaced generic discontinuity follow-up with an in-app styled prompt.
  • Added automatic SPT N-value calculations with safeguards for partial penetration and override.
  • Introduced depth-based Point Load geological material/weathering inheritance.

Status / limitations: Candidate version; later issues were addressed in subsequent builds.

v0.9.9.1Development candidate4 November 2026⌄

Data workflow changes including Geotech forms, Batch Edit and Smart Merge groundwork.

  • Expanded Rock Mechanics Geotech logging and create/edit workflows.
  • Introduced or expanded spreadsheet-style Batch Edit and conservative Smart Merge workflows.
  • Reorganised data import, exports and Data Review entry points.
  • Development-only candidate; not signed off for production.

Status / limitations: Not a production-approved release.
